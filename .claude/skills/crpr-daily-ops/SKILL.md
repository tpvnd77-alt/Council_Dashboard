# 일일 운영 루프

작업 디렉터리: `cr_pr_agent/`. 정기 실행 예: `/loop 1d /crpr-daily-ops` (또는 Windows 작업 스케줄러에 `crpr_daily.bat`).

1. `python cli.py daily` — inbox/ 처리 결과, 알림, 워크북 경로를 JSON 으로 받는다.
   - inbox 파일명 규칙: `[출처유형] 제목.pdf` (규칙이 없으면 언론으로 접수)
2. 결과를 이 순서로 짧게 정리한다:
   1. 기한 경과·D-Day·D-3 인 CRITICAL/HIGH 건 (DOC_ID, 제목, 기한)
   2. 사람 대기: 게이트1 분류 확정 / 담당자 검수 / 게이트2 조직장 판단 — 누가 무엇을 해야 하는지
   3. 처리 오류 — 원인 한 줄과 `python cli.py rerun <DOC_ID>`
   4. 오늘 inbox 에서 새로 들어온 건과 각 등급
3. 처리 오류가 같은 원인으로 2건 이상이면 원인을 먼저 고치자고 제안한다(자격 증명, 파일 형식 등). 오류 건을 반복 재실행하지 않는다.
4. 알릴 것이 없으면 "이상 없음" 한 줄로 끝낸다.
