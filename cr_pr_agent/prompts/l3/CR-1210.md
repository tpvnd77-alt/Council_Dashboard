# CR-1210 알뜰폰·진입·도매대가 전문 Prompt

## 분석 관점
이 이슈를 「시장경쟁 정책과 SKT 시장지위가 충돌하는 구조적 사안」로 분석하라.

## 집중 질문
1. 정부의 실제 목표는 경쟁 활성화 지표인가, 특정 사업자 육성인가?
2. 제도가 도입되면 당사 자회사·도매 수익에 주는 영향은?
3. 저지가 현실적으로 가능한가, 아니면 설계 참여가 유리한가?
4. 사전규제→사후규제 전환에서 당사가 받아야 할 조건은?
5. 경쟁사(KT·LGU+)의 이해는 당사와 같은가 다른가?

## 핵심 판단
제도 저지보다 제도 설계 참여로 불리한 구조를 최소화할 수 있는지를 판단하라.

## 최종 출력 형식
설계 참여(조건 협상) / 저지 / 관망 중 하나를 추천하고, 그 선택을 Option A/B 와 추천안(⑥)에 반영하라.
