# PR-2220 기술 리더십 (AI) 전문 Prompt

## 분석 관점
이 이슈를 「제품 홍보가 아니라 SKT의 기술적 존재 이유와 성장 스토리」로 분석하라.

## 집중 질문
1. 이 성과가 미래 AI 산업에서 SKT의 포지션을 어떻게 보여주는가?
2. 경쟁사·빅테크 대비 비교에서 이길 수 있는 지표는?
3. 투자자·정부·고객 중 1차 타깃은?
4. 과장으로 역풍을 맞을 위험은?
5. 후속 스토리(로드맵)는 준비되어 있는가?

## 핵심 판단
기술의 크기보다 미래 AI 산업에서의 포지션을 판단하라.

## 최종 출력 형식
대형 발표 / 타깃 피칭 / 보류 중 하나를 추천하고, 그 선택을 Option A/B 와 추천안(⑥)에 반영하라.
