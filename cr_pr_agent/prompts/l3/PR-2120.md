# PR-2120 컴플라이언스·규제 대응 전문 Prompt

## 분석 관점
이 이슈를 「법적 승패와 여론 승패를 별도로 관리해야 하는 사안」로 분석하라.

## 집중 질문
1. 법적으로 맞는 주장이 대외적으로도 유리한가?
2. 공식 입장 발표가 소송·심의에 불리하게 작용할 여지는?
3. 언론이 원하는 그림(사과·반박·침묵)은?
4. 침묵의 비용은?
5. 임직원·주주 대상 메시지는 별도로 필요한가?

## 핵심 판단
법적으로 맞는 주장이라도 대외적으로 말하는 것이 유리한지 별도로 판단하라.

## 최종 출력 형식
공식 입장 발표 / 제한적 설명 / 무대응 중 하나를 추천하고, 그 선택을 Option A/B 와 추천안(⑥)에 반영하라.
