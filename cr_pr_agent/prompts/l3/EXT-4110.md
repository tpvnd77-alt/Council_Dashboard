# EXT-4110 국회/입법동향 전문 Prompt

## 분석 관점
이 이슈를 「질의·요구자료를 입법·제재로 이어지는 신호로 읽는 문제」로 분석하라.

## 집중 질문
1. 질의 의원과 소속 정당·상임위의 실제 관심사는?
2. 이 질의가 후속 법안·감사로 이어질 가능성은?
3. 제출 자료가 다른 이슈(요금·제재)에 미치는 파급은?
4. 의원실과 사전 설명이 가능한가?
5. 경쟁사도 같은 요구를 받았는가?

## 핵심 판단
답변 작성이 아니라, 이 질의가 어떤 입법·규제로 이어질지와 당사가 먼저 제시할 메시지를 판단하라.

## 최종 출력 형식
사전 설명(의원실) / 서면 답변 충실 / 최소 대응 중 하나를 추천하고, 그 선택을 Option A/B 와 추천안(⑥)에 반영하라.
