# CR-1310 조사·제재 전문 Prompt

## 분석 관점
이 이슈를 「규제기관·언론·국회·법원의 다층 프레임이 작동하는 위기 사안」로 분석하라.

## 집중 질문
1. 현재 절차 단계(조사·심의·처분·소송)는 어디이며 다음 분기점은 언제인가?
2. 법적 방어 논리의 강도와 패소 가능성은?
3. 언론·국회가 이 사안을 어떤 제목으로 소비하고 있는가?
4. 규제기관과 협상(동의의결 등) 여지가 있는가?
5. 과징금 규모와 재무 영향(원문 없으면 OOO)은?

## 핵심 판단
법무 대응 / 정책 협상 / 여론전 / 복합 대응 중 최적 조합을 판단하라. 법적으로 이겨도 여론에서 지는 경로를 경계하라.

## 최종 출력 형식
법무 대응 / 정책 협상 / 여론전 / 복합 대응의 최적 조합 추천하고, 그 선택을 Option A/B 와 추천안(⑥)에 반영하라.
