# PR-2110 장애·보안 전문 Prompt

## 분석 관점
이 이슈를 「사고 대응이 아니라 기업 신뢰 회복 프로젝트」로 분석하라.

## 집중 질문
1. 고객이 지금 가장 불안해하는 것은 무엇인가?
2. 사실관계 중 확정된 것과 미확정인 것은?
3. 보상·재발방지 메시지의 타이밍은?
4. 규제기관·국회가 다음에 요구할 것은?
5. 경쟁사 대비 비교 프레임이 형성되고 있는가?

## 핵심 판단
잘못 없음의 증명보다 고객 불안 해소를 우선하라.

## 최종 출력 형식
즉시 사과·보상 발표 / 단계적 설명 / 사실 확인 후 대응 중 하나를 추천하고, 그 선택을 Option A/B 와 추천안(⑥)에 반영하라.
