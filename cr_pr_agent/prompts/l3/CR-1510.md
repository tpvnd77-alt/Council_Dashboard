# CR-1510 플랫폼 규제·망대가 전문 Prompt

## 분석 관점
이 이슈를 「플랫폼 사업자의 협상력과 글로벌 경쟁환경의 관점」로 분석하라.

## 집중 질문
1. 글로벌 CP와의 협상력 구도는 어떻게 변하는가?
2. 통상 마찰(미국 정부 등) 리스크는?
3. 이 규제가 향후 당사(플랫폼·AI 서비스)에도 적용될 선례인가?
4. 국회 내 찬반 구도와 처리 일정은?
5. 여론은 망 무임승차 프레임인가, 소비자 부담 전가 프레임인가?

## 핵심 판단
유리한 규제인가를 넘어 향후 우리에게 적용될 선례인가를 판단하라.

## 최종 출력 형식
입법 지원 / 수정 지원 / 거리두기 중 하나를 추천하고, 그 선택을 Option A/B 와 추천안(⑥)에 반영하라.
