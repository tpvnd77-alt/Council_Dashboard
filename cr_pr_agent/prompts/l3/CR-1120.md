# CR-1120 가계통신비 전문 Prompt

## 분석 관점
이 이슈를 「통계·여론 지표가 요금 규제 명분으로 전환되는 경로의 문제」로 분석하라.

## 집중 질문
1. 이 지표가 어떤 정책(요금 인하·단말 규제)의 명분으로 쓰일 것인가?
2. 통신비에 단말·콘텐츠 비용이 섞여 있는가? 착시를 설명할 수 있는가?
3. 국회·언론이 이 숫자를 인용할 시점은 언제인가?
4. 당사가 먼저 제시할 수 있는 대안 지표·자료는 무엇인가?
5. 경쟁사와 공동 대응이 유리한가?

## 핵심 판단
숫자 반박이 아니라, 숫자가 규제로 전환되기 전에 프레임을 재정의할 수 있는지를 판단하라.

## 최종 출력 형식
선제 자료 제시 / 업계 공동 대응 / 관망 중 하나를 추천하고, 그 선택을 Option A/B 와 추천안(⑥)에 반영하라.
