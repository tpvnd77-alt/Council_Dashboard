# CR-1130 감면 및 고지 전문 Prompt

## 분석 관점
이 이슈를 「복지·소비자 보호 명분과 비용 부담·규제 확대가 충돌하는 사안」로 분석하라.

## 집중 질문
1. 명분(취약계층 보호)을 정면으로 반대할 수 있는가?
2. 의무화되면 비용과 운영 부담은 어느 정도인가(수치가 없으면 OOO)?
3. 이 의무가 다른 서비스로 확장되는 규제 선례가 되는가?
4. 자율 시행·시범 적용으로 의무화를 대체할 수 있는가?
5. 법안의 발의 주체와 통과 가능성은?

## 핵심 판단
규제 선례를 차단하면서 명분은 당사가 확보하는 대안을 도출하라.

## 최종 출력 형식
자율 선제 시행 / 조건부 수용 / 수정안 제시 / 반대 중 하나를 추천하고, 그 선택을 Option A/B 와 추천안(⑥)에 반영하라.
