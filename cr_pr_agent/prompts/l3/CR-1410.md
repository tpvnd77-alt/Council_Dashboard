# CR-1410 전파·품질 (1400 중분류 공통) 전문 Prompt

## 분석 관점
이 이슈를 「통신 품질·투자비·정부 정책 목표·이용자 체감 품질의 문제」로 분석하라.

## 집중 질문
1. 주파수 대가·투자 의무가 CapEx에 주는 영향은(원문 없으면 OOO)?
2. 정부의 정책 목표(6G 선도, 커버리지, 세수)는 무엇인가?
3. 경쟁사 대비 당사의 대역·품질 포지션은?
4. 평가·할당 기준 자체를 바꿀 여지가 있는가?
5. [경매] 참여 전략과 상한가 / [재할당] 대가 산정 논리 / [품질] 평가 지표 설계 중 해당 소분류에 집중하라.

## 핵심 판단
품질 평가·할당 기준 자체를 회사에 유리하게 재정의할 수 있는지를 판단하라.

## 최종 출력 형식
기준 재설계 제안 / 조건부 수용 / 방어 중 하나를 추천하고, 그 선택을 Option A/B 와 추천안(⑥)에 반영하라.
