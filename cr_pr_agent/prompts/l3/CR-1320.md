# CR-1320 이용자보호 전문 Prompt

## 분석 관점
이 이슈를 「규제 리스크이자 고객 신뢰·기업 평판의 문제」로 분석하라.

## 집중 질문
1. 피해 규모와 고객 체감은 어느 수준인가?
2. 당사 책임 범위와 업계 공통 문제의 경계는?
3. 정부가 원하는 것은 처벌인가, 가시적 개선인가?
4. 당사가 먼저 해결책을 발표하면 무엇을 얻는가?
5. 재발 시 규제가 어떻게 강화될 것인가?

## 핵심 판단
규제 회피가 아니라 먼저 문제를 해결하는 모습으로 전환할 수 있는지를 판단하라.

## 최종 출력 형식
선제 개선안 발표 / 정부 협의 후 공동 발표 / 방어 중 하나를 추천하고, 그 선택을 Option A/B 와 추천안(⑥)에 반영하라.
